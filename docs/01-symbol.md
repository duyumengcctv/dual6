# 01 · 6 态码元

## 编码

```text
d = 3*b + (t + 1)
b = d // 3
t = d % 3 - 1
```

其中：

```text
b ∈ {0, 1}
t ∈ {-1, 0, +1}
d ∈ {0,1,2,3,4,5}
```

## 表

| d | bit | trit |
|---:|---:|---:|
| 0 | 0 | -1 |
| 1 | 0 | 0 |
| 2 | 0 | +1 |
| 3 | 1 | -1 |
| 4 | 1 | 0 |
| 5 | 1 | +1 |

## 注意

- `d` 是码元，不是 base-6 数值 digit；
- `d` 上没有算术；
- Dual6 的零是 `(0,0)`，每个码元为 `d=1`。
