# 13 · 适用场景与未来展望

> 这份文档把"它能用在哪"写成**可判断的条件**，而不是卖点。
> 每一条都附带"什么情况下它就不对"，以及对应的测量出处。

---

## 1. 逐元素侧通道 + 三值权重（双平面 D6P2）

**条件**：同一个元素既有三值主值，又有逐元素标志位（离群点、剪枝、
"该用高精度副本"），并且**同一个 kernel 在同一遍里读两者**。

**给什么**：一条顺序流，没有指针跳转，没有第二个文件可以失步。
掩码聚集时 `layout 1` 在此基础上再省 **−24.7% ~ −32.9%**
（`benchmarks/mask_structure.csv`，全零块 71.4% / 85.5% / 93.7%）。

**什么时候不对**：

- 两个通道不是逐元素对齐的。
- **而且注意：今天的格式基本都刻意避开这个形状。**
  AWQ / OWQ 用 **per-channel** scale，SpQR / SqueezeLLM 用**稀疏索引**——
  正是因为对齐的第二通道更贵。所以**这个场景目前是假设性的**：
  容器为它准备好了，不代表它已经存在。

---

## 2. 纯三值模型，但想要一个文件、一次校验（`FLAG_OMIT_BIT_PLANE`）

**条件**：纯三值负载；介质慢（网络盘 / 机械盘 / 端侧）或不想管多文件。

**给什么**：**1.60 bpw、59.2 ns/元素**，与 `TQ1_0`（1.60 / 59.3）持平，
额外得到 CRC32 与单对象帧。一次 `open`、一次 `mmap`、一次校验。

**什么时候不对**：

- 数据本来就快。**单帧加载并不更快**——最好的情况是 ±5% 内等价，
  多轮重复下稳定慢约 2%（`benchmarks/README.md` 的 E1 一节）。
  在 NVMe 或 cache 驻留场景里，帧头是纯开销。

---

## 3. 边服务边热更新（任何帧 + 协议）

**这一条不是容器的性质。**

故障注入（4 种容器 × 3 种更新协议 × 3 种加载器）表明：静默损坏由
**校验和 + 原子 `rename`** 决定，与字节怎么打包无关。一个普通 GGUF 套上
manifest 能得到同样的保护。

**测量到的是这条曲线的形状**（`benchmarks/fault_size.csv`）：

| 载荷 | 静默撕裂 |
|---:|---:|
| 4 KiB | 0.0% |
| 64 KiB | 0.0% |
| 512 KiB | 1.5% |
| 2 MiB | 17.0% |
| 8 MiB | 26.5% |

也就是说：**只要你在原地覆盖模型文件，不管什么格式，超过 512 KiB 就已经暴露。**

---

## 4. 要在 C / C++ / Rust 里写加载器（D6P1 / D6P2）

**条件**：加载器要嵌进推理引擎或驱动里，不想依赖 Python 生态。

**给什么**：固定头部 → 平面偏移；bit 平面可直接寻址，trit 平面就是现成的
5-trit/byte 打包，现有三值 kernel 不用改。嵌入成本是一次头部解析。

**注意"零拷贝"这个词**：bit 平面可以直接用；**trit 平面仍然需要解包**，
和今天每个 5-trit kernel 做的事情一样。

---

## 5. 明确不适用

| 场景 | 为什么 |
|---|---|
| 纯三值推理、无逐元素元数据 | 用 `TQ1_0`，省掉帧头 |
| 能整体进 cache | `int8` 的解码快一个数量级 |
| 跨层混合精度 | 通道不对齐 |
| MoE 路由表 | 路由是 `token × expert`，权重是 `expert × hidden`，形状不一致 |
| KV cache | 形状随序列增长，生命周期与权重不同 |
| 通用压缩 | 这是容器，不是编解码器 |

---

## 6. 展望

容器已经做完，缺的是**用它的理由**。两个信号能提供理由：

1. **需求侧**：出现一种公开的模型格式，其逐元素元数据与权重一起被读取。
   今天的格式把 scale 放组粒度、离群点放稀疏索引，正是为了不需要对齐的第二通道。
2. **供给侧**：三值**运算**原生执行。今天所有"三值推理"在相乘前都解包成 FP16，
   所以 bit 平面没有读者。

任一信号出现，接下来的工作已经确定：

| 工作 | 为什么 |
|---|---|
| `layout 1` 加块索引 | 现在读路径要扫一遍 flag，随机访问不是 O(1) |
| CRT 变体（`b = d % 2` 而非 `d // 3`） | 让两个通道的按位加同时无进位；需要重做符号表与全部 golden vector |

两者都是**规格变更**，不是重写。

**限制（必须写下来）**：这里没有任何一个测量跑在真实模型上；
最大载荷 8 MiB；故障注入的数字来自单机上的合成容器。
